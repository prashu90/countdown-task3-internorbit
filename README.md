Countdown Timer Project
📌 Project Overview

This project is part of my Internorbit Internship (Task 3).
The goal was to build a countdown timer using HTML, CSS, and JavaScript that counts down to a specific date and time.

The timer dynamically updates every second and provides a practical use case for real-world web applications.

🛠 Technologies Used

HTML5 – Input fields and timer structure

CSS3 – Styling the timer display and controls

JavaScript (ES6) – Logic to calculate and update remaining time

🚀 Features

Input fields to set target date & time

Real-time countdown display (days, hours, minutes, seconds)

Automatic update every second

Simple and clean UI design

Beginner-friendly project to understand JavaScript DOM manipulation
